# Yandex Music Quiet

Расширение Chrome меняет шкалу **штатного вертикального ползунка громкости справа в плеере Яндекс Музыки**. Никаких дополнительных регуляторов, всплывающих панелей или настроек.

## Установка

Готовый архив: [yandex-music-quiet.zip](https://github.com/jellybebra/yandex-music-quiet/releases/latest/download/yandex-music-quiet.zip).

1. Распакуйте ZIP в постоянную папку (если используете архив).
2. Откройте `chrome://extensions` в своём Chrome.
3. Включите **Режим разработчика / Developer mode** справа сверху.
4. Нажмите **Загрузить распакованное / Load unpacked** и выберите папку с `manifest.json`.
5. Перезагрузите открытую вкладку Яндекс Музыки.

Пользуйтесь обычным ползунком над значком динамика справа. В нижней части шкалы звук теперь существенно тише, а регулировка плавнее. Стрелки клавиатуры меняют положение на 0,1% вместо 1%. Ноль выключает звук, максимум сохраняет исходную полную громкость. Кнопка отключения звука работает как раньше.

Положение ползунка сохраняет сама Яндекс Музыка. Расширение ничего не записывает в её настройки и не требует повторного входа.

## Что изменилось

Вместо линейной передачи значения громкости используется плавная экспоненциальная шкала:

`output = (1000 ** position - 1) / 999`

| Значение штатного регулятора | Выходная амплитуда |
| --- | --- |
| 0% | 0% — тишина |
| 1% | ≈ 0,0072% |
| 10% | ≈ 0,10% |
| 50% | ≈ 3,07% |
| 100% | 100% |

Это амплитуда сигнала, а не субъективная громкость. В нижней части больше пространства для тихого прослушивания. Если положение до установки было очень низким, после установки может понадобиться немного поднять ползунок.

## Приватность и совместимость

- Только перечисленные домены Яндекс Музыки: music.yandex.ru, .com, .by, .kz, .uz.
- Нет API-разрешений, аналитики, записи звука, сети, серверов, зависимостей или доступа к учётной записи.
- Chrome 111+; работает и в установленном веб-приложении Яндекс Музыки того же профиля Chrome.
- Локальные HTML audio/video, включая отсоединённые `Audio`, новые плееры и переключение треков. Не управляет удалённой колонкой/Cast или отдельными Web Audio синтезаторами.
- При отключении, удалении или обновлении расширения перезагрузите вкладку Музыки, чтобы сбросить старые обработчики страницы.

## Разработка

Никакой сборки: обычные JavaScript и JSON. `audio-engine.js` в MAIN world перехватывает нативное свойство `HTMLMediaElement.volume`. Сайт читает своё исходное значение, а Chrome получает преобразованную амплитуду. Повторные записи не умножают ослабление. `slider.js` уменьшает шаг существующего `ChangeVolume` input и повторно применяет его при перерисовке React; остальные ползунки не затрагиваются.

Тест `tests/browser-check.js` запускается из корня репозитория через `playwright-cli run-code` в отдельном чистом тестовом Chromium. Передайте содержимое файла как аргумент команды. Он подключает скрипты на локально перехваченный HTML-стенд, не устанавливая расширение и не используя аккаунт пользователя. Проверяет реальные нативные значения громкости через изолированный JavaScript-мир и декодирование WAV. Тесты не входят в установочный ZIP.

Справка: [Chrome content scripts](https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts), [HTMLMediaElement.volume](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/volume).

Независимый проект, не связанный с Яндексом.
